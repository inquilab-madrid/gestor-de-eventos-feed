# Seguridad

## Informar de una vulnerabilidad

No abras una issue ni una PR. Escríbenos en privado desde [Security → Report a vulnerability](https://github.com/inquilab-madrid/gestor-de-eventos-feed/security/advisories/new). La vulnerabilidad se trata en ese aviso hasta que esté corregida.

Vale tanto para este repositorio (ejemplos, widget) como para el feed en sí (`participa.huelgaporlavivienda.org/api/public/`).

## Identificadores de cliente

Un identificador de cliente (`fc_…`) no es un secreto, pero tampoco lo publiques en una issue ni en un repositorio. Si se ha filtrado o alguien lo usa sin permiso, escribe a Coordinación de la campaña para cambiarlo.
