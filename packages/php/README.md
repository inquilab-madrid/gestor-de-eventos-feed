# inquilab-madrid/activity-feed

Cliente en PHP del feed público de actividades de la campaña por la Huelga General por la Vivienda. PHP 8.2 o posterior, sin dependencias.

Cómo usarlo: [docs/libraries.md](../../docs/libraries.md#php).

```bash
composer install
vendor/bin/phpunit   # pruebas contra spec/fixtures
```
