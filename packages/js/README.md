# @inquilab-madrid/activity-feed

Cliente en JavaScript y TypeScript del feed público de actividades de la campaña por la Huelga General por la Vivienda, para el navegador y Node.js 20 o posterior. Sin dependencias.

Cómo usarlo: [docs/libraries.md](../../docs/libraries.md).

```bash
npm install
npm test   # compila y pasa las pruebas contra spec/fixtures
```
